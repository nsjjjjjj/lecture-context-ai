# 데모 재현 기록

## 기준

- 앱: `nsjjjjjj/lecture-context-ai`, 해커톤 최종 병합 뒤 README 정리본 `68e2fa0ef2926b783b5e1f941ca9bdc90ab2630e`.
- 현재 로컬 AWS 실험 변경을 섞지 않았습니다. 위 커밋의 React·CSS·서버 코드를 변경하지 않았습니다.
- 촬영에 사용한 것은 앱에 원래 들어 있는 생성형 AI 샘플입니다. 팀원 녹음이나 사용자 데이터, 실제 API 키를 넣지 않았습니다.
- 테스트 대상은 샘플 강연이지 새 PDF 분석이나 실제 마이크 STT가 아닙니다. 예제 강연의 페이지 텍스트와 용어는 `GET /api/demo`가 반환하고, `/ws`에서 앱의 내장 자막이 재생됩니다.

## 같은 화면 열기

1. 원본 저장소의 위 커밋을 **지금 편집 중인 폴더와 분리한 작업 사본**에 준비합니다. 기존 작업 폴더에서 체크아웃을 바꿀 필요가 없습니다.
2. Node.js **22.17.0**과 pnpm **11.9.0**을 사용합니다. 빈 설정으로 시작합니다. 앱이 실행 중인 다른 프로젝트를 끄거나 운영 환경변수를 가져오지 않습니다.
3. 아래를 실행합니다. 의존성이 캐시된 경우 설치에 `--offline`을 추가할 수 있습니다.

```sh
pnpm install --frozen-lockfile
pnpm build
HOST=127.0.0.1 PORT=18787 NODE_ENV=production pnpm start
```

4. `http://127.0.0.1:18787/api/health`의 `services.speech`와 `services.gemini`가 모두 `false`인지 확인합니다. 다르면 외부 서비스 설정이 없는 로컬 환경을 다시 준비합니다.
5. 새 브라우저 프로필이나 비어 있는 브라우저 컨텍스트에서 `http://127.0.0.1:18787/#/lecture`를 엽니다. 뷰포트 1440×920 기준으로 찍었습니다.
6. **샘플 강연 바로 체험하기**를 선택합니다. 준비 화면에서 **데모 자막으로 미리보기**를 선택합니다. 화면의 자막 강조와 오른쪽 용어 설명이 같은 용어를 표시하는 장면을 캡처합니다. 용어 앱의 UI를 재구성하거나 합성하지 않습니다.
7. 촬영을 마치면 이 복제본을 위해 시작한 로컬 서버를 종료합니다.

## 두 시연에서 볼 것

- [샘플 강연 전체](media/lecture-demo.gif): 앱 시작, 용어집, 자막, 결과까지 이어지는 흐름이다. 서비스 설정 없이 내장 샘플로 실행된다.
- [발표 배치](media/lecture-presentation.gif): 실제 발표 때처럼 자막 기록 위에 별도 슬라이드를 띄운다. 네 장의 예시 슬라이드는 LLM과 Transformer, RAG, 환각, 파인튜닝 순서다. 앱 자체의 자막과 오른쪽 용어 설명은 원본 그대로다.
- [촬영과 편집 방법](slides/REPRODUCE-PRESENTATION.md) · WebSocket 이벤트

앱은 네 번의 임시 자막과 네 번의 확정 자막을 제공한다. ‘레그’가 확정 자막에서 RAG로 교정되는지, 오른쪽에 해당 용어 카드가 열리는지, 강연 뒤 결과로 이동하는지 순서대로 확인했다.
