# 발표 배치와 촬영 기록

발표 때 자막 기록 위에 별도 PPT를 띄워 둔 방식을 재현했다. PPT는 내장 샘플의 주제에 맞춰 다시 작성한 자료다. 강연 화면의 1440×920 브라우저 실녹화에 PPT 한 장씩을 겹치며, 앱 코드와 실시간 자막·용어 카드 화면은 바꾸지 않는다.

1. [시연 재현](../demo-reproduction.md)에 맞춰 격리한 앱을 실행한다.
2. Playwright를 설치한 새 작업 폴더에서 촬영 스크립트를 실행한다. 스크립트는 원본 WebM과 관찰 시점, 자막 이벤트를 남긴다.
3. 편집 스크립트를 같은 폴더에서 실행한다. 25fps 원본의 실시간 흐름을 유지하고, 자막 기록 안의 x=[116,916), y=[213,663) 범위에만 네 장을 올린다. 스크립트의 시간은 해당 녹화를 기준으로 하므로 다시 촬영하면 실제 라이브 화면과 자막 전환 시점에 맞춰 조정한다.
